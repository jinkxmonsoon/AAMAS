# CCT Journal Viability Assessment

## Viability decision

- Performance-oriented method paper viability: **low**.
- Protocol/benchmark/diagnostic-representation paper viability: **moderate** if claims are carefully bounded.
- Recommendation: continue only under Path B framing.

## Why Path A is not viable now

A new frozen scoring protocol v2 is not scientifically justified because Task 24A found only 6 unique feature vectors across 420 traces, 414 duplicate feature vectors, and several constant causal-flow features. The frozen scoring configuration provenance remains unresolved. A scoring protocol built on this representation would likely repeat the proxy/degeneracy failure mode.

## Why Path B is viable

Path B is viable because the repository now contains a protocol-first artifact trail:

- full-trace corpus construction and prediction-view hygiene;
- leakage and shortcut audits;
- descriptor-augmented artifact governance;
- causal-flow edge specification and prediction-view-safe extraction;
- full-corpus representation-only graph and feature audits;
- explicit negative findings and conservative readiness gates.

This supports a rigorous paper about benchmark/protocol construction and diagnostic representation failure modes, provided no superiority claims are made.

## Why Path C is not selected

Suspending journal submission entirely is not necessary if the article is reframed. The artifact is not ready for a performance method paper, but it can still support a protocol/benchmark/diagnostic-representation contribution.

## Viability risks

- Reviewers may expect performance results; the article must foreground that the contribution is diagnostic/protocol-first.
- Negative results must be framed as methodological evidence, not failed claims.
- The missing frozen scoring config must be disclosed as a reproducibility boundary.
- The redesigned feature layer remains highly degenerate; this must be presented as a limitation and finding.

## Final viability statement

The article remains viable only if the scientific backbone is shifted from "CCT improves attribution" to "CCT exposes and governs the representation/protocol risks that make failure attribution difficult." Current evidence supports a benchmark/protocol and diagnostic-representation paper, not a scoring-performance paper.
